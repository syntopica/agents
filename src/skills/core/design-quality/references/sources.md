# Design library manifest

Fetched 2026-10-01 into a session scratch directory that was not kept: the
`sources/...` paths below name where each clone lived, so re-fetch by URL and
commit when a source is needed again. The commit column is the HEAD that was
fetched, with its commit date. Stars were counted on the same day.

The verdict tells our tooling what to do with each source:

- **keep-core**: mine for rubric items and rule candidates.
- **keep-ref**: consult when a question comes up.
- **skip**: do not use.
