# Redesign done checklist

- [ ] `codeality-ui check` reports no finding that was not in the starting list,
      and every starting finding in scope is gone.
- [ ] No new `disable` entry without a reason a reviewer would accept.
- [ ] Light, dark and phone screenshots of every changed route were looked at
      after the last change.
- [ ] The project's own type-check, lint and tests pass.
- [ ] Changes live in tokens and shared components where the pattern repeats.
- [ ] No invented data, copy or feature reached the screen.
- [ ] Before and after screenshots of the same route, viewport and scheme were
      shown to the person, with one line per change.
