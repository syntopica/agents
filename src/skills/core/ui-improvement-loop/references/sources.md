# Sources and prior art (researched 2026-11-02)

Reusable skills and tools:

- Impeccable `distill` (https://github.com/pbakaus/impeccable): inventory of
  causes of clutter (redundancy, noise, confused hierarchy, interaction
  complexity) with disclosure and consolidation recipes. Closest prior art.
- jezweb `ux-audit`
  (https://github.com/jezweb/claude-skills/tree/main/plugins/dev-tools/skills/ux-audit):
  manifest of operated actions; Pass / Conditional / Fail / Incomplete.
- EliaAlberti `ux-audit` (https://github.com/EliaAlberti/ux-audit-skill):
  finding ids, screenshot evidence, a "not assessable from screenshots" section.
- Vercel web interface guidelines
  (https://github.com/vercel-labs/web-interface-guidelines): code-level rules
  with file:line findings.
- Anthropic `webapp-testing` and `frontend-design`
  (https://github.com/anthropics/skills).
- Aalto AIM visual complexity metrics (https://github.com/aalto-ui/aim):
  exploratory only.
